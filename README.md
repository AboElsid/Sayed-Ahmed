### 🔭 Flagship project

**[Mira — Assistive Voice Interface for Impaired Speech](#)** · 2022–Present · Solo

An interactive voice-command system for people with speech conditions (lisps, rhotacism, cleft palate, cerebral palsy) that mainstream recognition engines reject.

- Phonetic-distance matching engine using weighted edit-distance across articulatory features, not exact word matches
- Per-speaker consistency check to reduce false-positive triggers
- Arabic-specific text normalization (diacritics, hamza, ta-marbuta), fully on-device for privacy
- Lightweight C++ Windows taskbar UI for real-time status and voice control toggling
- Connected to smart-home hardware (Broadlink IR, Tuya) and validated against a 28-case regression suite

**Stack:** Python · C++ · Computational Phonetics · Broadlink IR · Tuya API
